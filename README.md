# MSITM6341-Python-Group-A: Telco Customer Churn

Midterm project for MSITM 6341 (Dallas Baptist University), Group A.
Predicting which customers of a telecom company are likely to cancel their
service (churn), using data cleaning, exploratory data analysis, and machine
learning in Python.

## Dataset

- **Name:** Telco Customer Churn (IBM sample dataset)
- **Source:** Kaggle – <https://www.kaggle.com/datasets/blastchar/telco-customer-churn>
- **Size:** 7,043 customers × 21 columns
- **Target:** `Churn` (Yes/No) – whether the customer left within the last month
- **Note:** This is a fictional company's data created by IBM for demonstration,
  not real customer records.

A copy of the raw CSV is included in `data/` so the project runs right after cloning.

## How to run

```bash
# 1. Clone and enter the repo
git clone https://github.com/<you>/MSITM6341-Python-Group-A.git
cd MSITM6341-Python-Group-A

# 2. (Optional) create a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the cleaning & preprocessing step (from the repo root)
python src/task_2_1_clean_preprocess.py
```

This creates three files in `data/processed/`:

| File | Contents | Used for |
|---|---|---|
| `telco_churn_clean.csv` | Cleaned, human-readable data | EDA (Task 2.2) |
| `telco_churn_train.csv` | Encoded + scaled training set (80%) | Modeling (Task 2.3) |
| `telco_churn_test.csv` | Encoded + scaled test set (20%) | Modeling (Task 2.3) |

1. Each task has a GitHub **issue**. Assign yourself before starting.
2. Create a **branch** for your work: `feature/<short-name>` (e.g. `feature/eda`).
3. Commit small, logical changes with clear messages.
4. Open a **pull request** into `main` that references the issue (`Closes #2`).
5. At least one teammate **reviews and approves** before merging.
6. Never commit directly to `main`.
